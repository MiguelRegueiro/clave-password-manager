# Archived Expo implementation

This directory preserves the previous React Native/Expo sources and generated Android project. It is not part of the active build. The active app is under `../../native/` and builds with `../../build-apk.sh`.

The archived code is retained for reference/recovery, not as a runnable second project: its old scripts, documentation and paths may no longer work after moving. Do not run Expo prebuild in the repository root. The root `node_modules/` is also unused by the new Android build.

No existing phone data was migrated or deleted. The native application has a separate application ID and signing identity.
